# Issue: 回帰予測の実装（predict）

## 概要
回帰タスクの `predict` を実装し、アルゴリズム指定時はそのモデルで予測、未指定時は最良モデルを用いて予測できるようにする。

## 背景
AutoML 層の `predict` が未実装であり、推論処理の実体を `ml/prediction` 配下へ移す必要がある。

## 完了条件
- `automl` 層の `predict` が薄いラッパーとして動作する。
- `ml/prediction` 配下に推論ロジックが実装されている。
- アルゴリズム指定がある場合は該当モデルを使用し、未指定の場合は最良モデルを使用する。
